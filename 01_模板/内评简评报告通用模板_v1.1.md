# 内评简评报告通用模板 v1.1

适用对象：内部信用评级条线的**简评报告**（一页半至三页）。本模板不按行业分支，只按「读者需要看到什么」组织。任何主体——工商企业、平台、项目公司、金融机构、REITs——走同一套骨架；差异不体现在模板里有几个行业版本，而体现在写作者从同一组问句里得到的答案不同。

配套文件：`内评简评报告通用模板_v1.1.json`（机器可读槽位，供程序与提示词消费）、`内评简评报告通用模板_v1.1.docx`（Word 骨架）。方法论见 `02_方法/内评简评报告写作方法论_v1.1.md`。

v1.0 的七个行业指标包已废止。废止原因见第六节。

## 一、体例的四个硬约束

整篇只有两级结构：**摘要层**（「正面：」「关注：」两个编号列表）与**正文层**（「1、基本情况」「2、行业情况」「3、点评」）。不加目录、不加评级结论段、不加免责声明。

摘要层是定性概括，除判断核心依赖量级外不列数据。判定口径是「删掉这个数字，这条判断还成不成立」，不成立才允许保留极少量数字。

正文层每段以一句**加粗的定性汇总句**开篇，其后是同口径数据展开，段末以「整体来看」类句子收口。分部业务段不加段首加粗；只有总述段、资产段、债务段、专题段加粗。

全篇统一合并口径、统一亿元单位、统一期次写法，不混母公司数，不混万元与亿元。

## 二、骨架与槽位

### 2.1 标题行

```
{{企业全称}}  主体：【{{内部评级代码}}】
```

企业全称取工商注册全名，不用简称。内部评级代码按内部体系填写（形如 `4B`、`5C`、`3D`），未定稿时留【待填】，不猜测。外部主体评级不写在此处，写进基本情况末尾。整行加粗、左对齐、首行缩进 2 字符。

### 2.2 摘要层：正面

固定 3 条，最多 5 条。每条一句话、单句成条、不换行、不列数据。

正面不按行业取材，按**信用支撑的来源**取材，只有四类：

第一类是**身份与外部支持**——谁拥有它、谁在背后兜底、是否有制度化的资金或政策通道。写的是层级与机制，不是称号。

第二类是**不可替代性**——它在所处的价值链条上是否难以被绕过。可替代性的来源可以是牌照与特许经营，可以是网络与区位，可以是技术壁垒与客户认证，可以是资源禀赋，也可以是规模本身带来的成本优势。判断标准只有一条：如果它明天停摆，谁最难受、多久能找到替代。

第三类是**经营的量价趋势与获现能力**——产出规模、价格或费率、产能或席位利用率的走向，以及经营性现金能否覆盖利息与资本开支。

第四类是**财务弹性**——债务期限结构、融资渠道是否通畅、未使用授信与可变现资产是否足够，决定它在压力下有多少腾挪空间。

排序按支撑力强弱，不按上述类别顺序硬填。某一类找不到可站住的事实，就跳过，用下一类补足，不为凑数把「公司治理规范」写成正面。

### 2.3 摘要层：关注

固定 3 条，风险集中时最多 5 条。同格式、同字数、同样不列数据。

关注按**风险的生成机制**取材，只有四类：

第一类是**天花板与集中度**——业务规模被什么卡住（产能、牌照额度、资源储量、区域人口、单一客户、单一项目），以及这个约束是刚性的还是可缓解的。

第二类是**盈利与现金流的脆弱性**——利润是否依赖非经常性项目、成本能否向下游传导、经营现金流与利润是否背离、应收与存货是否在吞现金。

第三类是**债务与再融资压力**——扩张速度是否超过内生现金流、短债占比与集中到期、对单一融资渠道的依赖、明股实债与表外承担。

第四类是**资产质量、或有与治理**——受限资产、减值计提是否充分、对外担保与未决诉讼、股权质押与控制权稳定性、关联方资金占用。

排序原则：先经营约束，再财务压力，最后资产与治理。同一事实在正面与关注中不得重复出现，一条里不塞两个不相关的判断。

### 2.4 正文：1、基本情况

单段，150–300 字，按固定五拍推进，不换段：

成立时间与前身 → 主营与功能定位（一句话说清「是谁、干什么、靠什么收钱」）→ 注册资本与实收资本、股东及持股比例、实际控制人 → 增资到位、上市状态、并表子公司数量（择要）→ 报告期内确有变化的股权、控制权或评级事项。

**注册资本与实收资本都要写。** 注册资本是认缴额、实收资本是到账额，两者差着就说明还有没缴的部分，这直接影响股东支持的成色；不一致时说明差额是什么（未实缴、分期到位、口径不同），不能只写其中一个。

**没有变化的事不写。** 控股股东及持股比例未发生变化、外部主体评级维持原级且展望未调整、审计机构未更换，都不写；董事长、总经理、董事的任免与内部部门调整这类与偿债能力无关的人事变动，也不写。判断方法：把这件事写成一条公告，读者会不会改变「能不能按期还钱」的判断？不会就整句删掉。反过来，控股股东或实际控制人变更为风险主体、控制权转移、评级下调或列入观察名单、审计意见类型变化，必须写，并写出对信用水平的影响方向。

该段只写身份，不写经营数据、不写财务指标。功能定位里必须出现「靠什么收钱」，这是后文所有分析的锚。

### 2.5 正文：2、行业情况

单段，250–420 字，独立一节，不与公司自身经营混写。这一段只回答「量由什么决定、价由谁定」，四件事按对公司的传导强弱排序，不按行业报告的目录顺序：

供需格局（行业所处阶段、产量或需求增速、产能利用率、需求端由哪几块构成）→ 价格与成本（产品价格或价格指数的走势与幅度、主要原材料与能源成本）→ 政策（产能置换、环保限产、补贴退坡、定价与结算机制中真正影响这家公司的那一条）→ 传导（上述变化怎样落到公司的量、价、毛利上，一句话接住转下一节）。

每个判断后面跟一个可核实的数（增速、幅度、利用率、区域投资额）。材料只给定性表述（「行业景气度下行」）时，改写到公司自己的数据上（公司产量降了多少、均价降了多少），不拿行业套话充数。不列行业风险清单——「行业竞争加剧」「政策存在不确定性」这类没有对象、也没有影响方向的句子一律不写；凡删掉后读者仍说不出「这件事影响公司哪个指标、往哪个方向」的句子，都不写。

**与总述段的分工**：行业的量、价、政策在这一节写完；总述段只写公司自己的收入结构、板块拆分与盈利主线，同一组行业数据不在两处各写一遍。

### 2.6 正文：3、点评

点评由八件按序拼装：**总述段 → 业务构成表 → 分部业务段 → 资产段 → 财务指标表 → 盈利段 → 债务段 → 或有／专题段**。除分部业务段外，每段都是「加粗汇总句 + 数据展开 + 收口句」。

**总述段（必选，300–500 字）。** 加粗句给出全文总判断：主体定位 + 经营趋势 + 但书，不带数字。随后落到公司经营与盈利的主线数据（钱的来源与公司自身做了什么），最后一句收入构成概览把读者引向业务构成表。外部条件的量、价、政策已在「2、行业情况」展开，这里不重抄。

三问是：**钱从谁那里来**（终端消费者、政府或单一付费方、上下游议价、金融市场）、**量由什么决定**（人口与流量、产能与开工、政策额度、项目进度）、**价由谁定**（市场竞价、政府定价、成本加成、长期协议）。这三问答完，外部条件就写完了，不需要判断它属于哪个行业。三问的答案决定这一段引什么数据：由人口与流量决定的引区域经济体量与客流货运量，由政策额度决定的引规划与批复，由项目进度决定的引投资与投产节奏。

**业务构成表（可选）。** 公司披露分板块收入时使用，四列固定「业务板块｜营业收入｜收入占比｜毛利率」，单位行「单位：亿元」，末行「营业总收入」或「合计」。不披露分板块毛利率的，该列留空，不推算。

**分部业务段（1）2）3）…，1–4 段）。** 每段 200–600 字，段首「1）××业务方面，」起句，不加粗。段内六拍：业务模式与产出能力 → 报告期的产出量 → 价格或费率与对应收入 → 成本结构与毛利率变动原因 → 项目、订单或资源储备 → 该板块的风险点。

第二拍「产出量」的计量单位由业务性质决定，不由行业决定，选择规则是：取该公司连续披露、可跨期比较、且与收入变动同向的那一个量。可能是产量、销量、处理量、吞吐量、载客量、通行量、发电量、订单金额、在管面积、席位或床位使用率、项目个数与投资进度。同一个主体内部不同板块可以用不同单位，不必强行统一。找不到这样的量，就跳过第二拍，直接写收入与价格，不拿无关指标充数。

**资产段（必选，200–400 字）。** 加粗句给出资产总判断（规模、结构、质量、受限）。展开：总资产规模 → 占比最高的前五大科目金额及占比（按最新期次实际金额降序重排，不得沿用上期名单只换数字）→ 各科目主要构成 → 受限资产金额与占比。

每个科目要写清「是什么」而不只是「多少」：存货是不动产、在途贸易品还是产成品；其他应收款是应收政府款、关联方占款还是保证金；在建工程是哪个项目、进度多少。货币资金是例外，不展开构成，只注明其中受限金额。

每个科目的句式固定为「科目 金额（占资产总额 ××.××%），主要为×××，再交代质量」：括号里只放占比，「主要为」把这个科目装的是什么说清（对手方、用途、形态），再落到能否变现、是否已质押、账龄落在哪一档。只写「规模较大」不给金额与占比，读者判断不了压了多少资产。

**盈利段（必选，250–450 字）。** 加粗句给出这一年利润是被什么吃掉的。收入与利润分开写：收入侧写本期数与同比，并把变动拆成量、价、结构三块，每块落到具体板块或产品；利润侧写利润总额与净利润的本期数与同比，由盈转亏、亏损扩大或收窄都要明写「亏损」。

亏损或利润大幅下滑必须逐项归因，一项一句、每句带金额，按影响从大到小排：毛利变动（量、价、成本各多少）→ 期间费用（销售、管理、研发、财务费用各多少、为什么变）→ 减值损失（资产减值与信用减值分别是多少、提在哪项资产上、依据什么提）→ 投资收益与公允价值变动 → 政府补助与其他收益 → 资产处置损益 → 所得税。写完回算一遍，各项方向与规模要能对上利润的变动。

归因只能落在材料有实数的项上，材料没给的项不写、不编比例。不能用「受行业景气度影响」「受宏观环境影响」「市场竞争加剧」这类不带数的话充当原因——那不是分析，是把要解释的事换了个说法。合并净利润材料没给时，写「净利润为负」并用量级证据（利润总额、同比降幅、减值金额）交代规模，不许用子公司净利润顶替、不许用净资产收益率倒算。段末收口写清哪些是偶发、哪些会持续、下一期是否重演。

总述段与盈利段分工：总述段给收入规模、构成与利润率方向，末句点明赚亏；盈利段从「降在哪一块、是量还是价」写起，再展开利润与归因。营业收入总数与各板块金额由总述段写过之后，盈利段不再重抄。

**财务指标表（必选）。** 表题「公司主要财务数据和财务指标（合并口径）」居中加粗，单位行「单位：亿元」。期次 3–4 列：最新期末在前，其后为最近完整年度与上一年度；只有两个年度可比时用 2 列，不为了凑三列而填不存在的期次。行项按第四节规则选取。缺数填 `--`，不留空、不推算、不用相近科目替代。盈利类两行不能省：「营业总收入」与「净利润」——利润总额扣掉所得税才是净利润，亏损与否看的是净利润，缺这一行，正文说亏损在表上找不到依托。净利润尤其不许用子公司数、净资产收益率或「利润总额×(1−所得税率)」倒算，材料没给就填 `--`。

**债务段（必选，250–450 字）。** 加粗句给出债务与偿债总判断（规模趋势、期限结构、即期压力、备用流动性）。六个要素顺序固定：负债总额与资产负债率 → 全部债务及长短债结构与占比 → 有息债务的融资构成（银行／债券／非标占比）→ 利息保障与经营获现 → 非受限货币资金对短债的覆盖 → 授信总额与未使用额度。或有事项不进这一段，独立成专题段。

顺序的理由是前三项回答「欠了多少、什么时候还」，后三项回答「拿什么还、还能借多少」。

**或有／专题段（可选，0–2 段）。** 出现下列情形之一时单列：存在需专门研判的重大风险（大额应收减值、控制权变更、评级下调、重大在建项目资金缺口、担保代偿风险）；或需给出前瞻判断。专题段的加粗句必须是完整判断句，不是标签。单列的标准是「这件事塞不进现有五段而不打断原有逻辑」，能塞就塞。

## 三、格式规范

正文中文楷体_GB2312、五号（10.5pt）、行距 1.15、首行缩进 2 字符、段前段后 0。标题行、摘要层两个小标题、正文两个小节标题、各段加粗汇总句、财务表表题加粗，其余不加粗。表格全框线，表头居中，数值列右对齐，首列左对齐。

数字写法：金额两位小数并带千分位；百分比两位小数；倍数两位小数；百分点差异写「下降 1.23 个百分点」不写「下降 1.23%」。年份写全，期次写「2026年9月末」「2026年1-9月」，不写「本期」「去年」。

## 四、财务指标表的行项选择规则

行项**不按行业匹配，按可得性与判断支点匹配**。分三层，逐层叠加，总量控制在 8–13 行。

### 4.1 第一层：无条件必选（不超过 9 行）

这九项任何主体都能从三张报表直接得出，且构成判断骨架，缺一项则某一分析环节无从落笔：资产总额、负债总额、所有者权益、资产负债率、营业总收入、净利润、经营活动现金流量净额、全部债务、总资本化比率。

「全部债务」按短期债务加长期债务计，口径在表下注明；台账只有有息债务口径时，行名写作「有息债务」或「全部债务（有息口径）」，全文统一，不与另一口径混用。

### 4.2 第二层：条件触发（满足条件才加，各条件彼此独立）

| 触发条件（以最近完整年度为准） | 增加行项 | 理由 |
|---|---|---|
| 披露营业成本 | 营业毛利率 | 有成本才有毛利分析 |
| 营业成本／营业收入 ≥ 60% | 营业成本 | 成本是主要变量，须单独看 |
| 投资收益／利润总额 ≥ 30%，或绝对值 ≥ 营业利润 30% | 投资收益 | 利润来源偏离主业 |
| 公允价值变动损益绝对值／利润总额 ≥ 10% | 公允价值变动损益 | 利润含非现金波动 |
| 其他收益（政府补助等）／利润总额 ≥ 30% | 其他收益 | 盈利对外部输血依赖 |
| 少数股东损益／净利润绝对值 ≥ 10% | 归属母公司股东的净利润 | 合并利润与股东可得利润背离 |
| 利息费用可识别，或 EBITDA 可算 | EBITDA、EBITDA利息保障倍数 | 偿债能力的分子分母 |
| 短期债务 > 0 | 货币资金／短期债务 | 即期覆盖 |
| 存货／总资产 ≥ 15% | 存货 | 变现周期与跌价风险 |
| （应收账款＋其他应收款）／总资产 ≥ 15% | 应收类款项合计 | 资金被占用 |
| 在建工程／总资产 ≥ 10% | 在建工程 | 后续资本开支压力 |
| 合同负债或预收款项／总资产 ≥ 10% | 剔除预收后的资产负债率 | 负债率被预收美化 |
| 披露受限资产金额 | 受限资产／总资产 | 资产可动用性 |
| 期间费用／营业收入 ≥ 15% | 期间费用率 | 费用刚性 |

阈值是默认值，可按主体情况调整，但调整要在交付说明里写明理由，同一主体前后期不得随意改。

### 4.3 第三层：主体专属（只在该主体披露时取用，不得强加）

受监管的金融机构加监管指标（不良率、拨备覆盖率、资本充足率、流动性比例、净息差、偿付能力充足率）；以单一资产池为偿付来源的主体加可供分配金额、分派率、单位造价或单价；项目公司加项目投资总额、已投比例、收费或处理单价。

这一层的判断标准是「该主体的偿付来源是否被专门监管或被合同锁定」。若答案为是，其监管或合同指标就比通用财务指标更有解释力；若答案为否，即使名字里带「金融」「投资」也不加这些行。

### 4.4 行项顺序

按「规模 → 结构 → 盈利 → 获现 → 债务 → 偿债」排列，不按重要性打乱。同一主体前后期行项保持一致；确需新增行项时，历史各期一并补齐，不留半列空行。

## 五、长度与装配校验

正文（不含表）2000–4000 字；摘要层 3–5 条正面 + 3–5 条关注；点评段落 5–9 段；表格 1–2 张；财务表期次 2–4 列。

装配完成后自检八项，任一项不通过即回退修改：

标题行企业全称与基本情况中的名称一致，内部评级代码已填；正面与关注各不少于 3 条且无数据、无重复；基本情况只写身份不写数据、且已写明注册资本与实收资本；行业情况独立成段、每个判断都带一个可核实的数、与总述段不重抄；全文没有「控股股东及持股比例未发生变化」「评级维持原级」「董事长/总经理变更」这类不影响偿债判断的交代；业务构成表合计等于营业总收入；分部业务段的产出量、价格、毛利率与业务构成表对得上；前五大资产科目按最新期次金额降序且占比合计不超过 100%；债务段短债、长债、全部债务三者自洽且与财务表一致；财务表每行有值或为 `--`，无一格凭空推算。

## 六、这一版改了什么，以及为什么

v1.0 把主体分成城投、产投、交通运输、制造业、房地产、金融、REITs 七类，各配一套指标行。这套做法在真实使用中会连错三处。

一是**归类本身不可靠**。判断主体属于哪一类，依赖名称关键词或「是否城投」这类标签，而名称常与实际业务不符：同一家「××控股」既可能是不动产出租，也可能是产业投资平台，还可能是实业集团；一家机场集团的非航业务收入可能超过航空性收入。归类一旦错，整张财务表的行项跟着错，而错的行项不会报错，只会静静地少一两行或多几行无意义的 `--`。

二是**行业清单永远不全**。七个包之外的主体——数据中心、新能源电站、收费公路的项目公司、融资租赁、担保公司、垃圾发电——都要临时打补丁，补丁越多，模板越像某几份样本报告的复制品。

三是**行业词会渗进判断句**。模板一旦写了「空域」「时刻」「矿权」作为关注槽位，写作者与模型就会去找这些词，找不到也硬写，最后形成的不是分析而是套词。

v1.1 的做法是把「行业」替换成两组可观测事实：一组是财务字段是否可得、占比是否够大（第四节），另一组是「钱从谁来、量由什么定、价由谁定」三问（2.5 节）。这两组都从数据与业务事实直接读出，不需要先给主体贴标签。补一个新的业务类型，只需要在第二、三层的触发条件里加一条，不必新增一个行业分支。

代价是模板不再给出「这个行业该看什么」的现成答案。这是有意的：现成答案正是过拟合的来源，而可靠的答案只能从该主体披露的事实里长出来。

## 七、写模板时的自检：什么不该写进模板

这一节约束模板自身的演进，防止下一版又把个案当通则。

**具体行业名词不得作为必填槽位。** 行业词只能出现在标注了「示例」的位置，且同一位置至少给三个不同行业的例子，避免单例被当作默认。

**数字区间来自体例而非样本。** 字数、段数、列数只由版面容量与阅读时长决定；不因为某份样本写了 3900 字就把它定为标准。改区间要能说出「版面为什么装不下」或「读者为什么看不完」。

**判断句不得模板化。** 模板可以规定「这里要写一句带但书的总判断」，不得规定「这里写盈利规模小、依赖补助」，后者是某家企业的结论。

**任何新增条款都要回答：换一家完全不同的主体，这条还成立吗。** 不成立则降级为例证，写进方法论或示例，不进模板正文。
