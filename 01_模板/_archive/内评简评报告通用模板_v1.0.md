# 内评简评报告通用模板 v1.0

适用对象：本模板用于内部信用评级条线的**简评报告**（一页半至三页），不区分行业。城投、产业、交通、地产、金融、REITs 共用同一骨架，行业差异只体现在「点评」的段落数量与财务指标表的具体行项上。

配套文件：`内评简评报告通用模板_v1.0.json`（机器可读槽位定义，供程序与提示词直接消费）、`内评简评报告通用模板_v1.0.docx`（Word 骨架，可直接套写）。方法论见 `02_方法/内评简评报告写作方法论_v1.0.md`。

## 一、体例的四个硬约束

整篇报告只有两级结构：**摘要层**与**正文层**。摘要层是「正面」「关注」两个编号列表，正文层是「1、基本情况」与「2、点评」。除此之外不加目录、不加评级结论段、不加免责声明。

摘要层是定性概括，**除判断核心依赖量级外不列数据**。金额、笔数、占比、比率一律下沉到正文；判定口径是「删掉这个数字，这条判断还成不成立」，不成立才允许保留极少量数字。

正文层每段以一句**加粗的定性汇总句**开篇，其后是同口径数据展开，段末以「整体来看」类句子收口。业务分部段（1）2）…）不加段首加粗，只有总述段、资产段、债务段、专题段加粗。

全篇统一合并口径、统一亿元单位、统一报告期表述（`2026年9月末`／`2025年`／`2026年1-9月`），不混用母公司口径，不混用万元与亿元。

## 二、骨架与槽位

### 2.1 标题行

```
{{企业全称}}  主体：【{{内部评级代码}}】
```

企业全称取工商注册全名，不用简称。内部评级代码按内部评级体系填写（形如 `4B`、`5C`、`3D`），外部主体评级不写在此处，写进「1、基本情况」末尾。标题整行加粗、左对齐、首行缩进 2 字符。

### 2.2 摘要层：正面

固定 3 条，最多 5 条。每条一句话、单句成条、不换行、不带小标题、不列数据。

| 槽位 | 通常取材 |
|---|---|
| 正面 1） | 股东背景与实控人层级、区域专营性或牌照稀缺性、行业地位与规模排序 |
| 正面 2） | 腹地经济／行业景气／政策支持等外部支撑，或核心资源禀赋（航线、矿权、土地储备、装机） |
| 正面 3） | 经营指标趋势（量、价、产能利用率）、盈利与获现、债务结构与融资弹性中最强的一项 |
| 正面 4）5）（可选） | 上述未用尽的其他支点，按强度降序补足 |

### 2.3 摘要层：关注

固定 3 条，风险集中时最多 5 条。与正面同格式、同字数、同样不列数据。

| 槽位 | 通常取材 |
|---|---|
| 关注 1） | 主业层面的结构性约束（空域、容量、资源枯竭、单一客户、政策定价、军民合用、机场时刻等） |
| 关注 2） | 财务层面的压力（资本支出与债务扩张、杠杆水平、短债覆盖、盈利对非经常性损益的依赖） |
| 关注 3） | 资产质量、或有事项、治理与股权（受限资产、应收账龄、对外担保、未决诉讼、股权质押、控制权变动） |
| 关注 4）5）（可选） | 前述未覆盖的重大风险点，按对偿债的影响强度降序 |

排序原则：先主体属性与经营约束，后财务，最后或有与治理。同一事实在正面与关注中不得重复出现，也不得一条里塞两个不相关的问题。

### 2.4 正文：1、基本情况

单段，150–300 字，按固定五拍推进，不换段：

成立时间与前身 → 主营与功能定位（一句话说清「是谁、干什么」）→ 注册资本、实收资本、股东及持股比例、实际控制人 → 报告期内股权或控制权变动 → 增资到位、上市状态、外部评级、并表子公司数量（择要）。

该段只写「是谁」，不写经营数据、不写财务指标。外部主体评级与评级机构写在本段末尾。

### 2.5 正文：2、点评

点评是报告主体，由「总述段 + 业务构成表 + 分部业务段 + 资产段 + 财务指标表 + 债务段 + 或有／专题段」七件按序拼装。除业务分部段外，每段都是「加粗汇总句 + 数据展开 + 收口句」的三段式。

**总述段（必选，300–500 字）。** 加粗句给出全文总判断：区域或行业地位 + 经营趋势 + 但书。随后展开区域经济或行业格局（城投写区域 GDP、财政、债务率；产业写行业供需、价格、集中度）、公司经营与盈利的主线数据、收入构成概览，最后一句引向业务构成表。

**业务构成表（可选）。** 公司披露分板块收入与毛利率时使用，四列固定为「业务板块｜营业收入｜收入占比｜毛利率」，单位行「单位：亿元」，末行为「营业总收入」或「合计」。不披露分板块毛利率的行业（如部分城投代建）该列留空，不推算。

**分部业务段（1）2）3）…，1–4 段）。** 每段 200–600 字，段首用「1）××业务方面，」起句，不加粗。段内按「业务模式与产能 → 报告期量价与收入 → 盈利与毛利率变动及原因 → 项目或订单储备 → 该板块的风险点」推进。板块数量按公司实际收入结构归并，占比低于 5% 的板块并入「其他业务」。

**资产段（必选，200–400 字）。** 加粗句给出资产总判断（规模、结构、质量、受限）。展开：总资产规模 → 前五大科目金额及占总资产比重（按新期次实际金额降序重排，不得沿用上一期的名单只换数字）→ 各科目主要构成 → 受限资产金额与占比。

**财务指标表（必选）。** 表题「公司主要财务数据和财务指标（合并口径）」居中加粗，表下或表上「单位：亿元」，三列期次（最新期末｜最近完整年度｜上一年度）。行项见第四节分行业指标包；某行无数据填 `--`，不留空、不推算。

**债务段（必选，250–450 字）。** 加粗句给出债务与偿债总判断（规模趋势、期限结构、即期压力、备用流动性）。展开：负债总额与资产负债率 → 全部债务及长短债结构与占比 → 有息债务的融资构成（银行／债券／非标占比）→ 利息保障倍数与经营获现 → 非受限货币资金对短债的覆盖 → 授信总额与未使用额度 → 或有事项（对外担保、未决诉讼、股东出资未到位）。

**或有／专题段（可选，0–2 段）。** 出现下列情形之一时单列：存在需专门研判的重大风险（大额应收减值、控制权变更、评级下调、重大在建项目资金缺口、担保代偿风险）；或需给出前瞻判断（行业景气度中期走势、项目投产后的产能与收入释放）。专题段的加粗句必须是完整判断句，不是标签。

## 三、格式规范

正文中文楷体_GB2312、五号（10.5pt）、行距 1.15、首行缩进 2 字符、段前段后 0。标题行、摘要层两个小标题（「正面：」「关注：」）、正文两个小节标题（「1、基本情况」「2、点评」）、各段加粗汇总句、财务表表题使用加粗；其余正文不加粗。表格使用全框线，表头居中，数值列右对齐，首列左对齐。

数字写法：金额两位小数并带千分位（`1,096.85万人次`、`73.15亿元`）；百分比两位小数（`48.28%`）；倍数两位小数（`2.77倍`）；年份写全（`2026年`），报告期写「2026年9月末」「2026年1-9月」，不写「本期」「去年」。

## 四、分行业指标包

财务指标表的行项按行业取用，同一主体前后期保持一致，不因换模板而增删。

| 行业 | 指标行 |
|---|---|
| 城投／产投（通用） | 资产总额、负债总额、所有者权益（经调整）、资产负债率、营业总收入、净利润、EBITDA、总债务、总资本化比率、EBITDA利息保障倍数、经营活动现金流量净额 |
| 交通运输（机场、港口、高速、铁路） | 资产总额、负债总额、资产负债率、营业收入、营业毛利率、净利润、总债务、总资本化比率、经营活动现金流量净额、非受限货币资金/短期债务 |
| 制造业／产业类 | 资产总额、负债总额、资产负债率、营业收入、营业成本、投资收益、公允价值变动损益、利润总额、净利润、总债务、总资本化比率、经营活动现金流量净额 |
| 房地产 | 资产总额、负债总额、资产负债率、营业收入、营业毛利率、净利润、剔除预收后的资产负债率、总债务、总资本化比率、经营活动现金流量净额 |
| 金融 | 资产总额、负债总额、所有者权益、营业总收入、净利润、不良率、拨备覆盖率、资本充足率、流动性比例 |
| REITs | 资产总额、负债总额、资产负债率、营业收入、EBITDA、可供分配金额、分派率、总债务、经营活动现金流量净额 |

行业专属的经营指标（机场的旅客吞吐量／货邮吞吐量／飞机起降架次、港口的货物吞吐量／集装箱量、高速的日均车流量／通行费收入、制造的产能利用率／产销率）不进财务表，写进对应的分部业务段。

## 五、长度与装配校验

整篇正文（不含表）1500–3000 字；摘要层 6 条（3 正面 + 3 关注）；点评段落 5–9 段；表格 1–2 张。装配完成后按下列六项自检，任一项不通过即回退修改：

标题行企业全称与「1、基本情况」中的名称一致，内部评级代码已填；正面与关注各不少于 3 条且无数据、无重复事项；「1、基本情况」未混入经营与财务数据；每段业务的量、价、毛利率三项与业务构成表能对上；前五大资产科目按最新期次金额降序且占比合计不超过 100%；债务段的短债、长债、全部债务三者加总自洽，且与财务表一致。
