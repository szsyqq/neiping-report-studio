# 内评简评报告写作方法论 v1.0

这套方法解决一件事：手上只有外部的评级报告、募集说明书、审计报告或结构化数据，怎样稳定地写出一份内部简评报告——数据不出错、判断有落点、正面与关注能立得住。

方法分四步：**认料 → 取数 → 写正文 → 提摘要**。顺序不能颠倒，尤其「提摘要」必须放在正文之后。摘要是在正文成型后从正文里抽出来的，不是先想好三条优点三条缺点再去找材料填。反过来做，写出来的摘要与正文必然两层皮：摘要讲的是宏观印象，正文讲的是具体事实，两者对不上。

配套文件：`01_模板/内评简评报告通用模板_v1.0.md`（骨架）、`01_模板/内评简评报告通用模板_v1.0.json`（机器可读槽位）。

## 一、认料：先看清手里有什么

外部材料的可信度不同，取数优先级也不同。同一事实出现两个值时，按下列顺序采信，低优先级来源的冲突值不采用，但要留痕。

| 优先级 | 材料 | 主要用途 | 局限 |
|---|---|---|---|
| 1 | 最新一期跟踪评级报告 | 摘要层的判断依据、经营与行业分析、评级机构关注点、历史财务数据 | 数据有滞后，通常只到上一年末或一季；观点是别人的 |
| 2 | 最新募集说明书 | 受限资产、应收账龄、债务明细、募投项目、股权穿透 | 期次更旧，仅作补充与穿透 |
| 3 | 审计报告、年报、半年报、季报 | 最新财务数据（总额、负债、现金流） | 无分析、无经营口径 |
| 4 | 交易所与清算所公告 | 控股权变更、评级调整、重大事项、突发事件 | 碎片化 |
| 5 | 财汇等结构化数据 | 债券清单、评级历史、主体档案、区域财政 | 口径可能与披露原文不同，需回原文核 |

评级报告的结构是标准的，写简评时基本上是把它的章节拆开重组。对应关系大致是：评级报告开头的「评级观点」与「正面／关注」是摘要层的原材料；「行业」与「业务」两节是总述段与分部业务段的主料；「财务分析」一节的资产、负债、盈利、现金流四块分别对应资产段与债务段；附表的财务数据与主要指标是财务指标表的底稿；「关注」与「评级展望」里点出的具体事项是关注条目的直接来源。

材料不全时有降级路径，但要降得明确：只有募集说明书时，经营分析可以写，但摘要层的趋势判断只能写截至募集说明书期次的事实，不能替发行人做前瞻；只有年报时，摘要层只能基于财务面提炼，正面第一条（股东背景与地位）需要从年报的「公司基本情况」与股权结构里补齐；只有结构化数据时，只能出数据骨架稿，摘要层留空待补。**不要用推测填补缺料**——一条没有材料支撑的正面或关注，会在评审时被整条推翻，连带影响其他五条的可信度。

## 二、取数：先定期次，再定单位，最后定口径

### 2.1 期次

一份报告里同时存在多个日期是正常的，关键是每个数字都标明它的期次，并且同类数字用同一个期次。

资产负债类（总资产、总负债、资产负债率、债务规模、货币资金、受限资产）取**最新可得期末**。收入盈利类（营业收入、净利润、毛利率、期间费用）取**最近一个完整会计年度**，同时并列最新的中期或季度数据作为边际变化。这样处理的理由是：资产负债是时点存量，越新越有意义；收入盈利是期间流量，半年数无法与年度数直接比较，混用会得出错误的同比。

报告期写法固定为三种：`2026年9月末`、`2025年`、`2026年1-9月`。不写「本期」「上年同期」「报告期内」，因为读者无法从上下文反推具体是哪一段。

### 2.2 单位

金额统一亿元，保留两位小数；小额（千万级及以下）可保留万元，但同一段内不混用。源材料常以万元列示，例如财务附表的 `长期投资 24,171.11`，换算成 2.42 亿元。查数时不能只按「亿元」检索，否则会把万元口径的披露误判为「未披露」，进而错改本来正确的旧值。

比率与占比保留两位小数；倍数保留两位小数；百分点差异写成「下降 1.23 个百分点」，不写成「下降 1.23%」。

### 2.3 口径

全篇用合并口径，不混母公司数。三个容易出错的口径要单独交代清楚：

**总债务与有息债务不是一回事。** 全部债务通常等于短期债务加长期债务，短债包含短期借款、一年内到期的非流动负债、应付票据等；有息债务的口径各家不同，有时剔除应付票据与专项应付款。写「全部债务 26.43 亿元，其中短期债务 1.80 亿元」时，融资构成那一段若引用的是有息债务 17.17 亿元，必须写明这是有息债务口径，并解释差额来自哪里（政府专项债、超长期国债资金等）。两个口径的数字不能混在同一句里。

**货币资金要用非受限口径。** 计算短债覆盖时，分子是货币资金减受限部分（保证金、质押定期存款），不是报表上的货币资金总额。若未披露受限金额，用总额计算并注明「未剔除受限」。

**占比之和超过 100% 时先找抵销行。** 分板块收入占比的分母常是抵销后合计，各板块占比之和自然超过 100%，与抵销项相抵才是 100%。这不是披露错误，写的时候把抵销项说明白。

### 2.4 复算

凡自己算的比率，都要写得出算式，并在草稿上留痕。四类复算必做：

分板块收入占比合计等于 100%（含抵销则说明抵销额）；短债加长债等于全部债务；总资产等于总负债加所有者权益；同比增速用同口径的两年数据重算一遍，与披露值比对，差异超过 0.1 个百分点就回去看基期是否被追溯调整。

量级检查同样必做：一个机场运营主体营业收入 8 亿元、总资产 73 亿元是合理的；如果算出毛利率 265%，几乎一定是把万元当成了亿元，或者把成本与收入的分子分母调换了。

### 2.5 混合数据期

一轮材料覆盖不同期次很常见：年报给上一完整年度，季报给最新期末，评级报告给行业判断但数据只到半年前。处理原则是各段分别标注自己的期次，不为了统一而往回退用旧数，也不为了统一而把不同期次的数凑成一句。没有最新数据的项目，沿用原口径并在交付说明里单列，不在正文里编造或推算。

## 三、写正文：一段一条因果链，段末收口

正文的判断力不来自形容词，来自「驱动因素 → 中间量 → 财务结果 → 偿债含义」这条链是否走通。一段话只走一条链，走不通的部分宁可删掉，不要并列罗列。

### 3.1 总述段

总述段承担全篇的定性结论，写法固定为三拍：先给区域或行业的外部条件（城投写区域 GDP、财政自给率、广义债务率；产业写供需、价格、集中度；交通写腹地经济体量与流量趋势），再给公司在这一条件下的经营与盈利主线（收入、净利润及其同比，最好能说明变动原因），最后用一句收入构成概览把读者引向业务构成表。

加粗的段首句是全篇总判断，句式为「主体定位 + 经营趋势 + 但书」，不带数字。例如「公司为苏南硕放机场运营主体，区域地位较高，营业收入保持较快增长，但整体盈利规模很小，利润对政府补助等非经常性损益依赖较大」。

### 3.2 分部业务段

按收入结构归并板块，占比低于 5% 的并入「其他业务」。每段走六拍：业务模式与产能资质（跑道、航站楼、矿权、产线、路段）→ 报告期的量（吞吐量、产量、车流量、销量）→ 价与收入 → 毛利率及其变动原因 → 项目或订单储备 → 该板块的风险点。

行业差别主要在第二拍用什么量：机场用旅客吞吐量、货邮吞吐量、飞机起降架次；港口用货物吞吐量与集装箱量；高速用日均车流量与通行费收入；制造用产能利用率、产销率与均价；城投代建用项目个数、总投资、已投资、回款。

这一段不加段首加粗。业务描述是事实层，加了加粗会与总述段、资产段、债务段的判断句混在一起，读者分不清哪句是结论。

### 3.3 资产段

先按最新期次的**实际金额降序重排**前五大科目，再逐项说明构成，最后落到受限。这一步最容易出错：很多人拿着上一期的前五大名单，只把每个数字换掉，结果排名已经变的科目还挂在原来的位置，新进入前五的科目被塞在句末。

每个科目要写清「是什么」而不只是「多少」：存货是土地还是产成品，其他应收款是应收政府款还是关联方占款，在建工程是哪个项目、进度多少。写不出「是什么」，说明材料没读到位，回去补，不要用「主要为……」含糊过去。

货币资金是例外，不展开构成（银行存款与其他货币资金没有分析价值），只在括号里注明其中受限的金额。

### 3.4 财务指标表

表题居中加粗，单位行右对齐，三列期次。行项按行业取用（见模板第四节的分行业指标包），同一主体前后期保持一致。缺数填 `--`，不留空、不推算，也不为了凑满表格而用相近科目替代。

### 3.5 债务段

七个要素顺序固定，不调换：负债总额与资产负债率 → 全部债务及长短债结构与占比 → 有息债务的融资构成（银行、债券、非标各占多少）→ 利息保障倍数与经营获现 → 非受限货币资金对短债的覆盖 → 授信总额与未使用额度 → 或有事项（对外担保、未决诉讼、股东出资未到位）。

顺序固定有理由：前四项回答「欠了多少、什么时候还」，后三项回答「拿什么还、还能借多少、有没有额外的坑」。违反这个顺序，读者读到一半会失去「到底还不上还不上」的线索。

### 3.6 专题段

出现下列情形时单列一段，加粗句必须是完整判断句而不是标签：大额应收或存货存在减值风险；控制权变更或股权质押比例过高；评级被下调或列入观察；重大在建项目存在资金缺口；对外担保存在代偿可能；行业景气度需要给中期判断。

单列的标准是「这件事没法塞进现有五段而不打断原有逻辑」。能塞进去的就塞，专题段过多会让报告失去简评的性质。

### 3.7 语言层

判断词要有级差：很强、较强、一般、较弱；处于……水平；可控、充足、尚可、趋紧、承压。不要全篇「较强」，那等于没有判断。

归因词用「受……影响」「使得」「导致」「带动」「受益于」，少用「意味着」。「意味着」是推理的痕迹，出现在正文里会让读者觉得你在替数据下结论。

删掉元话语：「这一结构的信用含义在于」「评级时应注意到」「需要明确的是」。这些是写给自己看的推理路标，不是报告内容。

可以用评级机构的叙述语言（段首归因、段中展开、段末「整体来看」收口、亿元口径、级差判断词），但不能把它的结论当论据。「中诚信国际认为公司竞争地位较强」不能作为你判断的依据；你若认可这个判断，要用自己能复算的数据把它重述一遍，比如用吞吐量占区域总量的比重、航线数量与基地航司数量来说明。

## 四、提摘要：正面与关注怎么写

这是全篇最见功力的一步，也是最容易写成套话的一步。

### 4.1 顺序：从正文倒抽，不从材料正推

正文定稿后，逐段回读，把每段里「能独立成立、且对偿债有含义」的判断句圈出来，形成候选池，再按准入规则筛选、去重、排序、限条。不要打开评级报告的「正面／关注」照抄——那是外部机构对其自身评级体系的表述，条数、口径、侧重都与内部简评不同，而且照抄会把别人的判断变成你的结论，一旦数据更新就站不住。

### 4.2 两个候选池

正面候选池从这些信号里捞：控股股东层级与实控人性质（国资委、财政部门、央企）、区域专营性或牌照稀缺性（唯一运营主体、独家特许经营、军民合用机场、5A 景区）、行业地位与规模排序（全国第几、区域第几、市占率）、外部支撑（政府补助、资本金注入、专项债与超长期国债、股东增资到位）、经营指标的趋势性改善（吞吐量创新高、产能利用率维持高位、量价齐升）、盈利与获现（毛利率提升、经营现金流覆盖利息）、债务结构（长期化、低成本、授信未用额度充足）。

关注候选池从这些信号里捞：正文里带「但」「需关注」「受限」「依赖」「压力」「不确定」「尚未」「有待观察」的句子；结构性约束（空域、容量上限、资源枯竭、单一客户集中、政策定价、军民合用）、财务压力（资本支出与债务扩张、杠杆高于同业、短债覆盖不足、盈利依赖非经常性损益、归母净利润为负）、资产质量（受限资产、应收账龄、存货去化、减值计提不足）、或有与治理（对外担保、未决诉讼、股权质押、控制权变动、审计机构频繁变更）。

### 4.3 准入三问

每条候选必须同时过三问，缺一问就退回正文，不立为摘要条。

**能被反驳吗？** 「公司整体经营稳健」无法被反驳，因此不是判断。「公司盈利规模很小，对政府补助依赖较大」可以被下一年的数据推翻，是判断。凡是「总体平稳」「持续优化」「有待观察」单独成条的，都是没想清楚。

**正文里有支撑吗？** 摘要条与正文段必须一一对应得上。摘要说「债务扩张压力」，正文债务段就要有债务增速与资本支出的具体数；对不上的摘要条要么补正文，要么删。

**对偿债有含义吗？** 摘要条要能落到偿付来源、弹性、成本、期限或外部支持之一。写「公司业务布局多元」如果没有说明多元如何带来稳定的现金流与偿债缓冲，它就只是公司简介。

### 4.4 一条一事，正反不重叠

一条只装一个问题。把「军民合用受限」和「容量接近上限」合成一条，评审时无法判断你到底在担心哪个；把「债务扩张」和「盈利薄弱」合成一条，更新数据时也没法只改一半。

同一事实不在正面与关注中各说一遍。典型错误是正面写「获得政府大力支持」、关注写「盈利依赖政府补助」，读者会认为前者是敷衍。处理办法是二选一：若补助是稳定的制度性安排（如公交成本规制补贴、机场运营补贴按公式拨付），放正面并说明机制；若补助波动大、占比高且不可预期，放关注；两者都不放，只在正文交代金额。

### 4.5 条数与排序

正面三条、关注三条是基准。风险确实集中时可以到五条（例如同时存在行业下行、股权质押、应收减值、评级下调），但五条必须条条独立，不能靠拆句凑数。少于三条说明材料没读透或判断没敢下。

排序不是按写作顺序，而是按对偿债的影响强度：主体属性与经营约束在前，财务压力居中，资产质量与或有治理在后。正面同理，股东背景与专营性在前，指标改善在后。

### 4.6 措辞模板

正面四种句式，按材料情况选用：

「公司实际控制人为××，控股股东为××，属市属国有企业，股东背景较好。」——股东与层级型，一句说清身份与含义。

「公司运营的机场主要服务××、××两地，腹地经济发达，随着××，未来吞吐量有望进一步提升。」——外部支撑型，条件是事实，推论带「有望」。

「××年疫情恢复之后，公司运营机场吞吐量持续增长，已远超疫情前水平并多次创历史新高。」——趋势型，只给定性趋势，不给数字。

「公司业务布局多元，多个板块能够提供稳定现金流，EBITDA 对利息的保障能力处于同行业较高水平。」——能力型，比较基准是「同行业」，不是具体倍数。

关注四种句式：

「××机场作为军民合用机场，业务运营可能会受到一定影响；且旅客吞吐量已接近设计容量上限，未来保障能力提升情况有待观察。」——约束型，给出机制 + 后续观察点。

「公司改扩建项目推进带动债务规模较快扩张，后续仍有较大规模投资支出需求，存在一定的债务扩张压力。」——传导型，用「带动」「存在……压力」把因果写出来。

「公司盈利规模很小，对政府补助及税收返还等非经常性损益依赖较大，归属母公司股东的净利润持续为负。」——财务特征型，特征是定性的，不写金额。

「公司应收类款项资金占用规模较大，同时存在多起未决诉讼，或有风险需要持续关注。」——或有型，两件事若同属或有且指向同一个后果（资金被占用、可能代偿），可以合并；否则拆开。

### 4.7 五种常见错法

**把数据搬进摘要。** 「2025 年旅客吞吐量 1,096.85 万人次，同比增长 4.4%」不是摘要，是正文。摘要是「吞吐量持续增长并多次创历史新高」。判定办法：删掉数字，这条还成立吗？成立就该删数字。

**正面写成公司简介。** 「公司成立于 2006 年，注册资本 25.50 亿元」是基本情况的内容，不是正面。正面要回答「这对偿债有什么好处」。

**关注写成行业综述。** 「我国防水行业整体处于低端产能过剩阶段」如果没有接上「因此公司面临什么」，就是行业段的内容。关注的主语必须是这个主体。

**正反自相矛盾。** 前面说「区域经济发达、客源充足」，后面说「需求不足导致收入下滑」，两句都留在摘要里，评审第一眼就会质疑整篇的可信度。发现矛盾时回正文核对，通常是两个判断用了不同期次的数据。

**条条都是「需持续关注」。** 六条里有五条以「需持续关注」结尾，等于什么都没说。收尾词要区分：确定的写「存在……压力」，不确定的写「……情况有待观察」，正在恶化的写「……有所上升/进一步扩大」。

### 4.8 双向校验

摘要定稿后做一次双向校验：逐条在正文里找到对应段落，逐段检查正文里最要紧的判断是否都进了摘要。前者防「摘要无据」，后者防「正文有料但摘要漏了」。两边都过一遍，摘要才算成型。

## 五、定稿前的十二项检查

标题行企业全称与基本情况中的名称一致，内部评级代码已填；正面与关注各不少于三条，均不含金额、百分比、倍数；摘要里没有重复事项，也没有正面与关注互斥的表述；基本情况只写身份不写经营与财务；总述段、资产段、债务段的段首句加粗且不带数字；分部业务段不加段首加粗；业务构成表的板块合计等于营业总收入，占比合计为 100%；财务表三列期次正确，缺数用 `--`；前五大资产科目按最新期次金额降序，占比合计不超过 100%；债务段短债加长债等于全部债务，且与财务表一致；所有数字能追溯到具体材料与期次；全文没有「本期」「去年」「大幅」这类无法核实的表述。

## 六、把方法用起来：两种执行方式

**人在环内（质量优先）。** 先取齐材料，按第二、三节写出正文，再按第四节倒抽摘要，最后走一遍第五节检查。适合首次覆盖、发行人结构复杂、或报告要上会的场合。

**机器起草（效率优先）。** 把材料交给程序，由程序完成取数、填表、按模板拼装段落，产出数据骨架稿与待补的判断句占位；人只做两步：补摘要层、改判断句。适合跟踪期更新、材料齐全、报告体例已定的场合。本项目的网站入口（`app/`）走的就是这条路径：企业名称进，材料与骨架稿出，判断仍由人定。
