待核对先让机器算，剩下的点到哪一句就是哪一句

自算值由程序复算销账，只有真核不上的才留下；留下的每条都能点进正文里那一句并选中，勾选可以整组一次勾完。

  • 定位做到句一级：每条待核对带着「哪一段 / 哪个输入框 / 第几个板块 / 整句原文 / 第几句」。点一下先滚到那一段，再把光标放进对应输入框、把那一句选中（浅蓝选中态），不用自己在五六百字里找那个数。
  • 板块段是整段可编辑，没法用选区接口，改成按字符偏移换算成 Range 去选，同样能选中那一句。
  • 机器先自己核对：正文里那些不是材料直接给出的数（占比、增速、变动百分点、倍数），提示词现在要求模型在 data_notes 里交底算式，写成『短期债务占比 = 3,421.53 ÷ 5,924.25 × 100%』。
  • 程序把交底的算式逐条复算，三条同时成立才销账：至少两个操作数、每个操作数都能在材料/台账里找到、算出来的值确实出现在正文里。算得上的不进待核对，收进「机器已自动核对 N 项」的折叠块，附算式可抽查。
  • 没交底算式的再退一步：用同一段里的数字穷举出所有两两运算的结果建表反查，能对上就认为「这是算出来的」。同段只有一二十个数，凑巧成立的概率低。
  • 不去材料全文里捞操作数：几千个数字两两组合几乎能凑出任何一个值，那是假核对，比不核对更糟。
  • 交底了但对不上的单独成组（操作数找不到 / 算出来与正文不符 / 算式本身算不出来），这类最该看——多半是抄错数或写错算式。
  • 打勾不必逐个：按问题类型分组，组头一个框勾整组，半选时显示为中间态；侧栏顶部「全勾」一次全部销账，再点一次撤回。单条仍可单独确认。
  • 组内每行写明「哪个数 · 哪一段 · 第几句」，下面一行是该句原文，长句自动折成一行的省略号，点开那一行才展开。
  • 顺手修掉两个算式匹配的错误：带容差的反解会把 4.31% 算成 4.69%（改成穷举建表并回代验算）；「同比上升 0.63 倍」被当成除法去凑（那是差额，小于 1 的倍数不再给除法档）；操作数取到结果自身算自证，已排除。

v222026-10-24 09:56

「该板块风险在于」不再另起一句，风险融进事实里

风险照写，但不再单起一句贴标签；谁付钱、什么时候能回、价格由谁定，直接接在已经说过的那件事后面。

  • 写作纪律第 7 条：分部段的最后一拍从「该板块风险点」改成「这一块受什么制约」——不是不写风险，是不把风险当标签贴。
  • 新增 7.1 专门讲这一拍怎么写：用「取决于」「受……制约」「一旦……将」把条件和后果连起来，让读者看到这件事怎么发生，而不是看到一句分类。
  • 给了正反两个例子对照——反例「……确认收入0.88亿元。该板块风险点在于回款依赖财政结算」；正例「……确认收入0.88亿元，同期回款0.31亿元，缺口随结算进度波动，回款节奏取决于财政资金安排」。
  • 给了检验法：把「该板块风险在于」删掉，剩下半句若主语仍是具体条件（回款、去化、价差、期限、担保对象）且能独立成句，合格；若删掉就读不通、或主语还是「该板块」，说明这句话本来就是硬贴上去的。
  • 「需关注……」也一并要求带条件：只挂一个风险名称（「需关注合规风险」）等于没写。
  • 程序兜底：模型真写了「该板块风险点在于，」这类引导语，后处理会连同前面的句号一起去掉、并成逗号，接在前一句后面——「……回款0.31亿元，回款节奏取决于财政安排」。带逗号和不带逗号两种写法都认。
  • 只处理后面能接整句的谓语（在于／来自／集中于／表现为／源自）；「风险是××」后半句多是名词短语，删了会缺谓语，留给校验提示，不硬擦。
  • 校验新增一条：仍有点题式表述的句子会列出来，提示改成「条件—后果」。只认小句开头的点题，「应收账款的回收风险主要来自政府结算」这种正常定语说法不会误报。
  • 用 21 份历史草稿回测：41 个板块段被自动改写，改写后残留点题句 0 处。

行尾那个小 × 换成右上角随鼠标浮现的圆圈，删错了还能撤回；按住序号上下拖就能调整先后。

  • 行尾右侧预留一条 24px 的空槽：圆圈出现、消失都不会让正文重新排版。叠在字上会挡住最后一两个字，突然挤开又会让整段跳一下。
  • 手机上没有鼠标悬停，圆圈一律常显并放大到 24px；空槽同步加宽，不压字。
  • 删除可以撤销：删完底部提示「已删除一条 · 撤销」，六秒内点一下，或按 ⌘/Ctrl+Z，条目原样回到原来的位置。删的是一条完整观点，没有后悔药太脆。
  • 焦点在正在改字的输入框里时，⌘Z 让给输入框自己的撤销，不会被这条提示抢走。

  • 拖动中途按 Esc 或指针被系统收走，退回原位，顺序不乱。
  • 拖到屏幕上下沿附近会自己滚，条目多的时候不用先滚到位置再拖。
  • 用 pointer 事件而不是浏览器自带的拖放：后者在手机上不触发，而这份报告手机上也要改。只轻点序号不会误触发拖动。
  • 列表下方加一行浅提示「按住序号可上下拖动换位置」，只有一条时自动收起——不说一句没人会去试。
  • 拖完落位的那一条会回一下底色，确认它停在这儿了。
