内评简评报告写作方法论 v1.1

这套方法解决一件事：手上只有外部的评级报告、募集说明书、审计报告或结构化数据，怎样稳定地写出一份内部简评报告——数据不出错、判断有落点、正面与关注能立得住。

方法分四步：认料 → 取数 → 写正文 → 提摘要。顺序不能颠倒，尤其「提摘要」必须放在正文之后。摘要是正文成型后从正文里抽出来的，不是先想好三条优点三条缺点再去找材料填。反过来做，摘要与正文必然两层皮：摘要讲宏观印象，正文讲具体事实，两者对不上。

配套文件：01_模板/内评简评报告通用模板_v1.1.md（骨架）、01_模板/内评简评报告通用模板_v1.1.json（机器可读槽位）。

一、认料：先看清手里有什么

外部材料的可信度不同，取数优先级也不同。同一事实出现两个值时，按下列顺序采信，低优先级来源的冲突值不采用，但要留痕。

优先级材料主要用途局限
1最新一期跟踪评级报告摘要层的判断依据、经营与行业分析、评级机构关注点、历史财务数据数据有滞后，通常只到上一年末或一季；观点是别人的
2最新募集说明书受限资产、应收账龄、债务明细、募投项目、股权穿透期次更旧，仅作补充与穿透
3审计报告、年报、半年报、季报最新财务数据（总额、负债、现金流）无分析、无经营口径
4交易所与清算所公告控股权变更、评级调整、重大事项、突发事件碎片化
5财汇等结构化数据债券清单、评级历史、主体档案、区域财政口径可能与披露原文不同，需回原文核

评级报告的结构是标准的，写简评基本上是把它的章节拆开重组：开头的「评级观点」与「正面／关注」是摘要层的原材料；「行业」与「业务」两节是总述段与分部业务段的主料；「财务分析」的资产、负债、盈利、现金流四块对应资产段与债务段；附表的财务数据与主要指标是财务指标表的底稿；「关注」与「评级展望」点出的具体事项是关注条目的直接来源。

材料不全时有降级路径，但要降得明确：只有募集说明书时，经营分析可以写，但摘要层的趋势判断只能写截至募集说明书期次的事实，不能替发行人做前瞻；只有年报时，摘要层只能基于财务面提炼，正面第一条（身份与外部支持）需要从年报的「公司基本情况」与股权结构里补齐；只有结构化数据时，只能出数据骨架稿，摘要层留空待补。不要用推测填补缺料——一条没有材料支撑的正面或关注，会在评审时被整条推翻，连带影响其他五条的可信度。

二、取数：先定期次，再定单位，最后定口径

2.1 期次

一份报告里同时存在多个日期是正常的，关键是每个数字都标明期次，同类数字用同一个期次。

资产负债类（总资产、总负债、资产负债率、债务规模、货币资金、受限资产）取最新可得期末。收入盈利类（营业收入、净利润、毛利率、期间费用）取最近一个完整会计年度，同时并列最新的中期或季度数据作为边际变化。理由是：资产负债是时点存量，越新越有意义；收入盈利是期间流量，半年数无法与年度数直接比较，混用会得出错误的同比。

报告期写法固定为三种：2026年9月末、2025年、2026年1-9月。不写「本期」「上年同期」「报告期内」，因为读者无法从上下文反推是哪一段。

2.2 单位

金额统一亿元，保留两位小数；小额（千万级及以下）可保留万元，但同一段内不混用。源材料常以万元列示，例如财务附表的「长期投资 24,171.11」，换算成 2.42 亿元。查数时不能只按「亿元」检索，否则会把万元口径的披露误判为「未披露」，进而错改本来正确的旧值。

比率与占比保留两位小数；倍数保留两位小数；百分点差异写成「下降 1.23 个百分点」，不写「下降 1.23%」。

2.3 口径

全篇用合并口径，不混母公司数。三个容易出错的口径要单独交代。

全部债务与有息债务不是一回事。 全部债务通常等于短期债务加长期债务，短债含短期借款、一年内到期的非流动负债、应付票据等；有息债务的口径各家不同，有时剔除应付票据与专项应付款，有时不含政府专项债。同一句里不能混用两个口径；若融资构成一段引用的是另一口径，必须写明差额来自哪里。

货币资金要用非受限口径。 计算短债覆盖时，分子是货币资金减受限部分（保证金、质押定期存款），不是报表上的货币资金总额。未披露受限金额时用总额计算并注明「未剔除受限」。

占比之和超过 100% 时先找抵销行。 分板块收入占比的分母常是抵销后合计，各板块占比之和自然超过 100%，与抵销项相抵才是 100%。这不是披露错误，写的时候把抵销项说明白。

2.4 复算

凡自己算的比率，都要写得出算式，并在草稿上留痕。四类复算必做：

分板块收入占比合计等于 100%（含抵销则说明抵销额）；短债加长债等于全部债务；总资产等于总负债加所有者权益；同比增速用同口径两年数据重算一遍，与披露值比对，差异超过 0.1 个百分点就回去看基期是否被追溯调整。

量级检查同样必做，且必须用该主体自己的历史区间作参照，不用行业平均数：把当期每一项除以营业收入或总资产，看得到的比值是否落在它过去三到五年的区间内；跳出区间的项，要么是业务发生了变化，要么是单位或口径错了。这一步比记任何行业的「正常值」都可靠——行业均值会随周期漂移，而同一主体的历史区间相对稳定。

2.5 混合数据期

一轮材料覆盖不同期次很常见：年报给上一完整年度，季报给最新期末，评级报告给行业判断但数据只到半年前。处理原则是各段分别标注自己的期次，不为了统一而往回退用旧数，也不为了统一而把不同期次的数凑成一句。没有最新数据的项目，沿用原口径并在交付说明里单列，不在正文里编造或推算。

三、写正文：一段一条因果链，段末收口

正文的判断力不来自形容词，来自「驱动因素 → 中间量 → 财务结果 → 偿债含义」这条链是否走通。一段话只走一条链，走不通的部分宁可删掉，不要并列罗列。

3.1 总述段：用三问代替行业套路

写外部条件时不要先问「这是哪个行业」，而问三件事：

钱从谁那里来。 终端消费者、单一付费方（政府或大客户）、上下游议价、还是金融市场本身。付费方越集中、定价越被动，收入的可预测性与可调整性差得越多。

量由什么决定。 人口与流量、产能与开工率、政策额度与批复、项目进度、客户订单。这一问决定你引什么数据，也决定「增长」是可持续的还是阶段性的。

价由谁定。 市场竞价、政府定价、成本加成、长期协议。这一问决定毛利率的稳定性，以及成本上行时能否转嫁。

三问答完，外部条件就写完了，不需要判断它属于哪个行业。同一套问句用在机场、水务、代建、光伏组件、融资租赁上都成立，答案自然不同。

加粗的段首句是全篇总判断，句式是「主体定位 + 经营趋势 + 但书」，不带数字。它的作用是让读者在第一句就知道你的结论倾向，所以必须是一句可以被反驳的话。

3.2 分部业务段：六拍，第二拍按业务性质定量

按收入结构归并板块，占比默认低于 5% 的并入「其他业务」（按披露层级可调）。每段六拍：业务模式与产出能力 → 报告期的产出量 → 价格或费率与对应收入 → 成本结构与毛利率变动原因 → 项目、订单或资源储备 → 该板块的风险点。

第二拍的计量单位由业务性质决定，不由行业决定。选择规则只有一条：取该公司连续披露、可跨期比较、且与收入变动同向的那一个量。可能是产量、销量、处理量、吞吐量、载客量、通行量、发电量、订单金额、在管面积、席位或床位使用率、项目个数与投资进度。同一主体的不同板块可以用不同单位，不必强行统一；同一个板块在不同年份也应尽量用同一个单位，否则同比失去意义。

找不到这样的量就跳过第二拍，直接写收入与价格。拿一个和收入不同向的指标来充数（比如用员工人数说明规模、用专利数说明竞争力），读者会以为你在回避真正的经营数据。

这一段不加段首加粗。业务描述是事实层，加了加粗会与总述段、资产段、债务段的判断句混在一起，读者分不清哪句是结论。

3.3 资产段：先重排，再解释「是什么」

先按最新期次的实际金额降序重排前五大科目，再逐项说明构成，最后落到受限。这一步最容易出错：很多人拿着上一期的前五大名单，只把每个数字换掉，结果排名已经变的科目还挂在原来的位置，新进入前五的科目被塞在句末。

每个科目要写清「是什么」而不只是「多少」：存货是不动产、在途贸易品还是产成品；其他应收款是应收政府款、关联方占款还是保证金；在建工程是哪个项目、进度多少；无形资产是土地使用权、特许经营权还是软件。写不出「是什么」，说明材料没读到位，回去补，不要用「主要为……」含糊过去。

货币资金是例外，不展开构成（银行存款与其他货币资金没有分析价值），只在括号里注明其中受限的金额。

3.4 财务指标表：行项由字段决定，不由行业决定

行项按模板第四节的三个层次选取：九到十一项无条件必选，其余按「字段是否可得 + 占比是否够大」逐条触发，受监管或被合同锁定现金流的主体再加专属层。总数控制在 11–15 行。

这样选的好处是换主体不用换模板：不需要先判断它属于哪一类，也不会因为分类错误而少算或多算。代价是每次都要实际算一遍占比再决定加不加，不能照抄上一家的行项。这一步不能省——占比是判断的一部分，算过才知道哪几个科目真正重要。

缺数填 --，不留空、不推算，也不为了凑满表格而用相近科目替代。

3.5 债务段：七个要素，顺序固定

负债总额与资产负债率 → 全部债务及长短债结构与占比 → 有息债务的融资构成（银行、债券、非标各占多少）→ 利息保障倍数与经营获现 → 非受限货币资金对短债的覆盖 → 授信总额与未使用额度 → 或有事项（对外担保、未决诉讼、股东出资未到位）。

顺序固定有理由：前四项回答「欠了多少、什么时候还」，后三项回答「拿什么还、还能借多少、有没有额外的坑」。违反这个顺序，读者读到一半会失去「到底还不还得上」的线索。

3.6 专题段：只在塞不进去时单列

出现下列情形时单列一段，加粗句必须是完整判断句而不是标签：大额应收或存货存在减值风险；控制权变更或股权质押比例过高；评级被下调或列入观察；重大在建项目存在资金缺口；对外担保存在代偿可能；需要给出中期景气判断。

单列的标准是「这件事没法塞进现有五段而不打断原有逻辑」。能塞进去的就塞，专题段过多会让报告失去简评的性质。

3.7 语言层

判断词要有级差：很强、较强、一般、较弱；处于……水平；可控、充足、尚可、趋紧、承压。不要全篇「较强」，那等于没有判断。

归因词用「受……影响」「使得」「导致」「带动」「受益于」，少用「意味着」。「意味着」是推理的痕迹，出现在正文里会让读者觉得你在替数据下结论。

删掉元话语：「这一结构的信用含义在于」「评级时应注意到」「需要明确的是」。这些是写给自己看的推理路标，不是报告内容。

可以用评级机构的叙述语言（段首归因、段中展开、段末「整体来看」收口、亿元口径、级差判断词），但不能把它的结论当论据。外部机构说「公司竞争地位较强」不能作为你的判断依据；你若认可，要用自己能复算的数据把它重述一遍——比如用产出量占区域总量的比重、可替代供给的数量、客户切换成本来说明。

四、提摘要：正面与关注怎么写

这是全篇最见功力的一步，也是最容易写成套话的一步。

4.1 顺序：从正文倒抽，不从材料正推

正文定稿后逐段回读，把每段里「能独立成立、且对偿债有含义」的判断句圈出来形成候选池，再按准入规则筛选、去重、排序、限条。不要打开评级报告的「正面／关注」照抄——那是外部机构对其自身评级体系的表述，条数、口径、侧重都与内部简评不同，而且照抄会把别人的判断变成你的结论，一旦数据更新就站不住。

4.2 两个候选池按机制分类，不按行业分类

正面看四类来源：身份与外部支持（谁拥有它、有无制度化的资金或政策通道）；不可替代性（停摆时谁最难受、多久能找到替代）；经营量价与获现（产出、价格、利用率、现金流覆盖）；财务弹性（期限、渠道、授信、可变现资产）。

关注看四类机制：天花板与集中度（规模被什么卡住，约束是刚性还是可缓解）；盈利与现金流脆弱性（非经常性依赖、成本传导、现金流与利润背离、应收存货吞现金）；债务与再融资压力（扩张速度、短债集中、渠道依赖、表外承担）；资产质量、或有与治理（受限、减值、担保、诉讼、质押、占用）。

分类的意义在于穷尽性：一个主体无论多特殊，它的支撑只能来自这四类，风险也只能落在这四类。具体的词——无论是航线、矿权、批文、认证、床位还是席位——都只是某一类在当前主体上的具体形态，不能反过来把词写进模板当成必填项。

4.3 准入三问

每条候选必须同时过三问，缺一问就退回正文，不立为摘要条。

能被反驳吗？ 「公司整体经营稳健」无法被反驳，因此不是判断。「盈利规模很小，对补助依赖较大」可以被下一年的数据推翻，是判断。凡是「总体平稳」「持续优化」「有待观察」单独成条的，都是没想清楚。

正文里有支撑吗？ 摘要条与正文段必须一一对应得上。摘要说「债务扩张压力」，正文债务段就要有债务增速与资本支出的具体数；对不上的摘要条要么补正文，要么删。

对偿债有含义吗？ 摘要条要能落到偿付来源、弹性、成本、期限或外部支持之一。写「业务布局多元」如果没有说明多元如何带来稳定的现金流与偿债缓冲，它就只是公司简介。

4.4 一条一事，正反不重叠

一条只装一个问题。把两个约束合成一条，评审时无法判断你到底在担心哪个；把「债务扩张」和「盈利薄弱」合成一条，更新数据时也没法只改一半。

同一事实不在正面与关注中各说一遍。典型错误是正面写「获得政府大力支持」、关注写「盈利依赖政府补助」，读者会认为前者是敷衍。处理办法是二选一：若补助是稳定的制度性安排（按公式拨付、纳入预算、有文件依据），放正面并说明机制；若补助波动大、占比高且不可预期，放关注；两者都不放，只在正文交代金额。

4.5 条数与排序

正面三条、关注三条是基准。风险确实集中时可以到五条，但五条必须条条独立，不能靠拆句凑数。少于三条说明材料没读透或判断没敢下。

排序按对偿债的影响强度，不按写作顺序：经营约束在前，财务压力居中，资产质量与或有治理在后。正面同理，身份与不可替代性在前，指标改善在后。

4.6 措辞：先定机制，再选句式

四种句式按机制选用，不是四个模板：

身份型——一句说清「谁拥有它、这意味着什么」，不停留在称号。示例：「公司实际控制人为××市国资委，控股股东为××集团，在区域内承担××职能，外部支持具备制度基础。」（示例中的职能与层级需按实际替换，不可套用）

外部条件型——条件要是事实，推论带「有望」「存在可能」。示例：「公司主要服务××区域，该区域××指标连续增长，随××投产，产出规模有望进一步扩大。」

趋势型——只给定性趋势与方向，不给数字。示例：「近三年产出规模持续增长，已超过上一轮扩能前的水平。」

能力型——比较基准用「自身历史」或「可比的同类主体」，不用无依据的「同行业平均」。示例：「经营性现金流对利息的覆盖保持在较好水平，且高于自身近五年均值。」

关注的四种机制对应四类收尾：约束型给出机制与观察点（「……受××限制，产能释放节奏有待观察」）；传导型写明路径（「××推进带动债务规模扩张，后续仍有较大支出需求，存在一定的再融资压力」）；特征型定性描述（「盈利规模较小，对非经常性项目依赖较大」）；或有型说明后果（「应收类款项占用规模较大，同时存在多起未决诉讼，或有风险需持续关注」）。

4.7 五种常见错法

把数据搬进摘要。 摘要里出现「同比增长 4.4%」即是正文内容。判定办法：删掉数字，这条还成立吗？成立就该删数字。

正面写成公司简介。 成立时间、注册资本是基本情况的内容，不是正面。正面要回答「这对偿债有什么好处」。

关注写成行业综述。 「我国××行业整体产能过剩」如果没有接上「因此该主体面临什么」，就是行业段的内容。关注的主语必须是这个主体。

正反自相矛盾。 前面说「区域需求充足」，后面说「需求不足导致收入下滑」，两句都留在摘要里，评审第一眼就会质疑整篇的可信度。发现矛盾时回正文核对，通常是两个判断用了不同期次的数据。

条条都是「需持续关注」。 六条里有五条以「需持续关注」结尾，等于什么都没说。收尾词要区分：确定的写「存在……压力」，不确定的写「……情况有待观察」，正在恶化的写「……有所上升／进一步扩大」。

4.8 双向校验

摘要定稿后做一次双向校验：逐条在正文里找到对应段落，逐段检查正文里最要紧的判断是否都进了摘要。前者防「摘要无据」，后者防「正文有料但摘要漏了」。

五、定稿前的十二项检查

标题行企业全称与基本情况中的名称一致，内部评级代码已填或标【待填】；正面与关注各不少于三条，均不含金额、百分比、倍数；摘要里没有重复事项，也没有正面与关注互斥的表述；基本情况只写身份不写经营与财务；总述段、资产段、债务段的段首句加粗且不带数字；分部业务段不加段首加粗；业务构成表的板块合计等于营业总收入，占比合计为 100%（有抵销则说明）；财务表期次为 2–4 列且与时点匹配，缺数用 --；前五大资产科目按最新期次金额降序，占比合计不超过 100%；债务段短债加长债等于全部债务，且与财务表一致；所有数字能追溯到具体材料与期次；全文没有「本期」「去年」「大幅」这类无法核实的表述。

六、让方法不过拟合：三条自我约束

写过一批报告之后，最容易发生的事是把某一类主体的写法当成通用写法，把某一份样本的结构当成标准结构。三条约束用来防这件事。

不从样本倒推规则。 一份报告写得好，不代表它的段落顺序、字数、取舍就是标准。规则只从两处来：读者的阅读需要（一页半到三页、先结论后依据），以及事实的可得性（有什么数据才能写什么）。凡是想加一条「这类主体一般要写××」，先问：这是读者的需要，还是上一份样本的习惯。

不把行业词写成必填项。 一旦模板里出现「此处写空域限制」「此处写矿权」，写作者与模型就会去找这些词，找不到也硬写，最后形成的是套词而不是分析。正确的写法是留下机制问句（「此处写规模被什么卡住」），让具体主体自己长出词。

不复用结论。 上一家的判断句即使句式漂亮也不能直接搬，因为判断的对象变了。可以复用句式，不可以复用结论；可以复用结构，不可以复用取舍。

判断是否过拟合，用一句话检验：把这家企业换成一家业务完全不同、但同样需要评级的公司，这份模板或这段方法还成立吗。 成立，是通则；不成立，就是个案，应该写进示例而不是模板。

七、把方法用起来：两种执行方式

人在环内（质量优先）。 先取齐材料，按第二、三节写出正文，再按第四节倒抽摘要，最后走一遍第五节检查。适合首次覆盖、结构复杂、或报告要上会的场合。

机器起草（效率优先）。 把材料交给程序，由程序完成取数、填表、按模板拼装段落，产出数据骨架稿与待补的判断句占位；人只做两步：补摘要层、改判断句。适合跟踪期更新、材料齐全、报告体例已定的场合。本项目的网站入口（app/）走的就是这条路径：企业名称进，材料与骨架稿出，判断仍由人定。
